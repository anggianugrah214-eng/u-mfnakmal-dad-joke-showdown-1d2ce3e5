A single original dad joke, at most 200 characters, for make.fun's "Dad Joke Showdown" bounty. `main.ts` (Node 22, standard library only, no network) writes the joke to `/output/entry.txt`: a sourdough starter leaves a note saying it was never let rise to the occasion, so now it is doughing its own thing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
